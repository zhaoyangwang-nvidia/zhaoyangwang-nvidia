## 🔭 What I'm Working On

| Area | What it means in practice |
|------|---------------------------|
| ⚡ **Speculative Decoding** | One-model Eagle3 / MTP, dynamic trees, rejection sampling — pushing acceptance length without paying for it in latency. |
| 🧵 **Runtime & Scheduler** | In-flight batching, the PyExecutor loop, request management overhead — keeping the GPU fed. |
| 🎬 **CUDA Graphs** | Full-iteration capture, sync-free execution, killing kernel-launch overhead. |
